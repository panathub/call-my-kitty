# AGENTS.md

## Project

- TanStack Start + React 19 app deployed to Cloudflare Workers.
- Main user-facing screen is the voice game in [src/components/game/CallTheCatGame.tsx](/Users/panat/Documents/call-my-kitty/src/components/game/CallTheCatGame.tsx).

## Commands

- `npm run dev` starts the Vite dev server.
- `npm run build` creates the production build.
- `npm run preview` previews the built app locally.
- `npm run lint` runs ESLint.
- `npm run format` runs Prettier.

## Entry Points

- Client/start setup: [src/start.ts](/Users/panat/Documents/call-my-kitty/src/start.ts).
- Worker SSR entry: [src/server.ts](/Users/panat/Documents/call-my-kitty/src/server.ts).
- Router setup: [src/router.tsx](/Users/panat/Documents/call-my-kitty/src/router.tsx).
- Home route: [src/routes/index.tsx](/Users/panat/Documents/call-my-kitty/src/routes/index.tsx).

## Conventions

- Do not manually edit [src/routeTree.gen.ts](/Users/panat/Documents/call-my-kitty/src/routeTree.gen.ts); it is generated by TanStack Router.
- Use the `@/*` alias for imports from `src` when it keeps paths clearer.
- Keep server-only code in `*.server.ts` files or mark it with `@tanstack/react-start/server-only`; ESLint explicitly rejects the Next.js `server-only` package.
- Preserve the custom SSR error handling in [src/start.ts](/Users/panat/Documents/call-my-kitty/src/start.ts) and [src/server.ts](/Users/panat/Documents/call-my-kitty/src/server.ts) when changing request flow.

## Build And Runtime Notes

- Vite config is wrapped by [vite.config.ts](/Users/panat/Documents/call-my-kitty/vite.config.ts) using `@lovable.dev/vite-tanstack-config`. Do not add the usual React, Tailwind, TanStack Start, or Cloudflare plugins manually unless you first remove the wrapper.
- Cloudflare Worker config lives in [wrangler.jsonc](/Users/panat/Documents/call-my-kitty/wrangler.jsonc); production behavior should be validated against the Worker target, not only Vite preview.

## Known Pitfalls

- Lovable asset manifest files like [src/assets/cat-scene.mp4.asset.json](/Users/panat/Documents/call-my-kitty/src/assets/cat-scene.mp4.asset.json) point at `/__l5e/...` URLs that only work in the Lovable sandbox. For production or local preview, ship real static assets from `public/` or another runtime-served location instead of relying on those manifest URLs.
- The UI library under [src/components/ui](/Users/panat/Documents/call-my-kitty/src/components/ui) is shadcn-style generated code. Prefer matching its existing patterns over broad refactors.
